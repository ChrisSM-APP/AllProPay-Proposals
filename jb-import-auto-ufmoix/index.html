The Flexibility You Asked For

You and the GM asked to see both paths before deciding, so the account is built to do either one without starting over.

  • Start on Edge with $0 card cost to the shop. If the GM would rather keep absorbing the fee on lower-ticket work, we move you to flat interchange-plus on the same account, no reapplication.
  • The customer-facing card rate is set at signup and can be tuned for your average ticket, so big repairs are not carrying an outsized fee.
  • The ACH lane stays available either way for large invoices that are better off the card rails entirely.
